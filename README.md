# 🎃 Halloween Candy Battle — ОНЛАЙН мультиплеер

3D игра 1 на 1 через интернет на Хеллоуин! Без ботов — только живые игроки.

## Как играть вдвоём
1. Один игрок придумывает код комнаты (например TYKA) и жмёт **Создать игру**
2. Второй вводит ТОТ ЖЕ код и жмёт **Подключиться**
3. Кто соберёт 15 конфет 🍬 — победил!

Можно играть одному (кнопка тренировки).

## Файлы
- `index.html` — игра
- `config.js` — настройки (конфеты для победы, время, скорость)
- `textures.js` — хеллоуин-текстуры (земля, стены, призраки)
- `net.js` — онлайн-сеть через PeerJS (без своего сервера)

## Управление
WASD — бег, ПРОБЕЛ — прыжок, мышка — камера.
